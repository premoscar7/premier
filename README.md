# Baby Kids 🦒 — สมุดบันทึกลูกน้อย

แอปติดตามพัฒนาการและดูแลลูกน้อยสำหรับคุณพ่อคุณแม่ ใช้งานฟรี 100%
เก็บข้อมูลในเครื่อง (ไม่ต้องสมัครสมาชิก ไม่ต้องมี server) ติดตั้งลงหน้าจอมือถือได้เหมือนแอปจริง และใช้งานออฟไลน์ได้

---

## ✨ ฟีเจอร์

- **🍼 บันทึกการกินนม** — นมแม่ (ซ้าย/ขวา/สองข้าง), นมขวด (ml), อาหาร
- **😴 การนอน** — เวลานอน-ตื่น คำนวณระยะเวลาอัตโนมัติ
- **💩 ผ้าอ้อม** — ฉี่ / อึ / ทั้งคู่ พร้อมหมายเหตุ
- **📈 น้ำหนัก & ส่วนสูง** — กราฟเทียบเกณฑ์มาตรฐาน **WHO** (P3–P97) แยกชาย/หญิง
- **🎯 พัฒนาการตามวัย** — เช็กลิสต์ milestone ตามช่วงอายุ (อ้างอิง CDC/WHO) 4 ด้าน
- **🤖 ผู้ช่วยพัฒนาการ** — วิเคราะห์พัฒนาการ ให้คำแนะนำ และเตือนสิ่งที่ควรสังเกตตามวัย
- **🌡️ สุขภาพ (ไข้ & ยา)** — บันทึกอุณหภูมิ แจ้งเตือนเมื่อมีไข้ + บันทึกยา/วิตามินที่ให้
- **📊 สรุปรายสัปดาห์** — กราฟมื้อนม ชั่วโมงนอน ผ้าอ้อม ย้อนหลัง 7 วัน พร้อมค่าเฉลี่ย
- **📸 ไดอารี่ความทรงจำ** — เก็บภาพ + โน้ตโมเมนต์พิเศษ (ยิ้มครั้งแรก ฟันซี่แรก ฯลฯ) พร้อมบอกอายุลูก ณ วันนั้น
- **🛒 ของต้องซื้อให้ลูก** — เช็กลิสต์ของใช้ 40+ รายการ แยกหมวด เพิ่มเองได้
- **🩺 นัดหมอ & วัคซีน** — สร้างตารางวัคซีนอัตโนมัติจากวันเกิด (อ้างอิง EPI ไทย)
- **💾 สำรอง/กู้คืนข้อมูล** — ส่งออกเป็นไฟล์ และนำเข้าเพื่อย้ายเครื่องได้

## 🚀 วิธีนำขึ้นเว็บให้ใช้ฟรี (เลือกวิธีใดวิธีหนึ่ง)

แอปนี้เป็นเว็บ static ล้วน (ไม่ต้อง build) จึงอัปโหลดขึ้นได้ทันที

### วิธีที่ 1 — Netlify Drop (ง่ายสุด ไม่ต้องติดตั้งอะไร) ⭐
1. เปิด **https://app.netlify.com/drop**
2. **ลากทั้งโฟลเดอร์นี้** ไปวางในหน้าเว็บ
3. รอสักครู่ จะได้ลิงก์ใช้งานทันที (เช่น `https://ชื่อสุ่ม.netlify.app`)
4. สมัคร/ล็อกอินฟรีเพื่อเก็บลิงก์ไว้ถาวร (จะเปลี่ยนชื่อ subdomain เองก็ได้)

### วิธีที่ 2 — Vercel ผ่าน GitHub
1. สร้าง repo ใหม่บน **github.com** แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
2. เข้า **https://vercel.com** → ล็อกอินด้วย GitHub → **Add New → Project**
3. เลือก repo ที่เพิ่งสร้าง → กด **Deploy** (ไม่ต้องตั้งค่าอะไร Vercel ตรวจเจอ `vercel.json` เอง)
4. ได้ลิงก์ `https://ชื่อโปรเจกต์.vercel.app`

### วิธีที่ 3 — Vercel CLI (ต้องมี Node.js)
```bash
npm i -g vercel
cd โฟลเดอร์นี้
vercel
```
> เครื่องนี้ยังไม่มี Node.js — ถ้าจะใช้วิธีนี้ ติดตั้งก่อนที่ https://nodejs.org

## 📲 ติดตั้งลงมือถือ (ใช้เหมือนแอปจริง)

หลัง deploy แล้ว เปิดลิงก์ในมือถือ:
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม" (Add to Home Screen)
- **Android (Chrome):** เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"

ทั้งพ่อและแม่ติดตั้งในมือถือของตัวเองได้ (ข้อมูลแยกกันในแต่ละเครื่อง)

---

## 💡 ข้อควรรู้

- **ข้อมูลเก็บในเครื่องนี้เท่านั้น** (localStorage) — ไม่ซิงค์ข้ามเครื่องอัตโนมัติ
  ถ้าอยากย้าย/แชร์ข้อมูลระหว่างมือถือ 2 เครื่อง: ไปที่ **ตั้งค่า → ส่งออกข้อมูล** แล้วส่งไฟล์ไป **นำเข้าข้อมูล** ในอีกเครื่อง
- แนะนำกด **ส่งออกข้อมูลสำรอง** เป็นระยะ กันข้อมูลหายถ้าล้างแคชเบราว์เซอร์
- ข้อมูลพัฒนาการ/วัคซีน/เกณฑ์การเติบโต เป็น **แนวทางอ้างอิง** เด็กแต่ละคนมีจังหวะต่างกัน หากมีข้อสงสัยควรปรึกษากุมารแพทย์

## 🗂️ โครงสร้างไฟล์

```
index.html              หน้าหลัก
css/styles.css          ธีมน่ารักสไตล์เด็ก
js/data.js              ข้อมูลอ้างอิง (พัฒนาการ, วัคซีน, ของใช้, เกณฑ์ WHO)
js/store.js             จัดการข้อมูล localStorage
js/app.js               logic + ทุกหน้าจอ + กราฟ + ผู้ช่วย AI
manifest.webmanifest    ตั้งค่า PWA
sw.js                   service worker (ใช้งานออฟไลน์)
icons/                  ไอคอนแอป
vercel.json             ตั้งค่า deploy
```

ทำด้วย 💛 สำหรับคุณพ่อคุณแม่
